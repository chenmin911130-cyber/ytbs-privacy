隐私说明 · v0.3.0

所有文字不离开本机。YouTube 字幕和你选择翻译的网页正文，都由 Chrome 内置的本地翻译（Translator API）在你的设备上翻译。扩展不把字幕、视频标题或网页文字发送给我们或任何第三方翻译服务；0.3.0 不包含任何云端翻译代码。

首次使用时，Chrome 可能会从 Google 下载中文语言模型（这是 Chrome 自身的组件下载，不包含你的页面文字）。下载完成后可离线翻译。

无广告。不收集数据：不收集个人身份资料、账号、浏览历史或使用统计，不采集音频，没有任何分析或追踪脚本，也不生成安装 ID。

保存在本机的内容：字幕颜色与字号通过 Chrome 同步（chrome.storage.sync）；其余设置、悬浮按钮停靠位置和语言包状态保存在 chrome.storage.local；字幕译文缓存保存在本机 IndexedDB。网页译文只保存在当前标签页内存中，关闭或离开页面即清除。从 0.2.x 更新时，旧版的 API Key、匿名安装 ID 与代理令牌会被自动删除。卸载扩展会清除所有本机扩展数据。

权限用途：storage 保存上述设置；activeTab 与 scripting 仅在你点击「翻译此页」、右键菜单或按快捷键时，把翻译脚本注入当前标签；contextMenus 提供右键菜单；www.youtube.com 主机权限用于在播放器上显示双语字幕。
