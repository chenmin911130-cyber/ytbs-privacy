隐私说明 · v0.4.0

所有文字不离开本机。YouTube 字幕、你选择翻译的网页正文，以及你在扩展阅读页打开的 PDF，都由 Chrome 内置的本地翻译（Translator API）在你的设备上翻译。扩展不把字幕、视频标题、网页文字或 PDF 内容发送给我们或任何第三方翻译服务；扩展不包含任何云端翻译代码。

PDF 只在本机处理，不会上传。PDF 的解析（pdf.js）和扫描件的英文文字识别（Tesseract.js 与英文模型）都打包在扩展内，在你的设备上运行，不从网络加载任何代码。你打开的 PDF 文件、识别出的文字和译文只保存在当前阅读页的内存中，关闭阅读页即清除；从网页打开 PDF 时，文件会在本机临时交给阅读页，阅读页取到文件后即删除；如果阅读页没有打开，这份临时副本会在下次从网页打开 PDF 时被清除（超过 10 分钟的会被删掉）。

首次使用时，Chrome 可能会从 Google 下载中文语言模型（这是 Chrome 自身的组件下载，不包含你的页面文字）。下载完成后可离线翻译。

无广告。不收集数据：不收集个人身份资料、账号、浏览历史或使用统计，不采集音频，没有任何分析或追踪脚本，也不生成安装 ID。

保存在本机的内容：字幕颜色与字号通过 Chrome 同步（chrome.storage.sync）；其余设置（含 AI 中文字幕开关和 PDF 阅读页的滚动同步设置）、悬浮按钮停靠位置和语言包状态保存在 chrome.storage.local；字幕译文缓存保存在本机 IndexedDB。网页译文只保存在当前标签页内存中，关闭或离开页面即清除。从 0.2.x 更新时，旧版的 API Key、匿名安装 ID 与代理令牌会被自动删除。卸载扩展会清除所有本机扩展数据。

权限用途：storage 保存上述设置；activeTab 与 scripting 仅在你点击「翻译此页」、右键菜单或按快捷键时，把翻译脚本注入当前标签，或读取当前标签里你要打开的 PDF；contextMenus 提供右键菜单；www.youtube.com 主机权限用于在播放器上显示双语字幕。

可选网站权限：安装时不申请任何其他网站的权限。只有当你在 PDF 阅读页点击「授权该站点并重新获取」时，扩展才会为该 PDF 所在的那一个网站申请读取权限，用来下载你打开的这一份 PDF；不会一次申请多个网站或所有网站。扩展只在读取这份 PDF 时使用该权限；已授权的网站会显示在 Chrome 的扩展管理页，你可以随时在那里移除。本机 PDF 通过选择文件或拖入打开，扩展不申请访问本机文件网址的权限。
